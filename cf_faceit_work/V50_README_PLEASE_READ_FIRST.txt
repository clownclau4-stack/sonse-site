CF FACEIT v50 — установка демо-галереи и общих статусов

ФАЙЛЫ
• CF_FACEIT_V50_GAME_DEMOS.zip — готовая папка сайта PAGES_UPLOAD и миграции SQL/41, SQL/42, SQL/43.
• SQL/43_game_demos.sql — отдельный SQL-файл для новой демо-галереи и лимита загрузок.

УСТАНОВКА
1. Скачай ZIP и сохрани резервную копию текущих файлов сайта и базы данных.
2. В Supabase открой SQL Editor. Запусти только ещё не установленные миграции, строго по порядку: SQL/41_player_host_and_moderation.sql, затем SQL/42_sponsor_badge_and_profile_customization.sql, затем SQL/43_game_demos.sql. Для демо-галереи обязательна SQL/43; она создаёт закрытый Storage-бакет, таблицы и серверные функции. Если SQL/41 и SQL/42 уже применены, повторно их не запускай.
3. Распакуй ZIP. Загрузи содержимое папки PAGES_UPLOAD в корень сайта на VPS, сохранив подпапки audio, icons и images, а также manifest.webmanifest и sw.js. Подтверди замену файлов.
4. Открой сайт, войди в онлайн-аккаунт и обнови страницу. В меню-бургере открой «Демки». Проверь загрузку файла, скачивание от другого вошедшего игрока и удаление своей демки. Проверяй с интервалом: следующая новая загрузка для аккаунта доступна через час.
5. Проверь аватары, галочки, значок спонсора и роли в общих списках и чате.

ЧТО ВАЖНО
• Меню и галерея доступны после входа; гостевой режим не добавлен.
• Формат CounterFlame в игровых файлах проекта не подтверждён. В этой версии разрешён распространённый формат .dem, до 50 МБ. Не загружай другой формат, пока расширение не будет проверено и allowlist не обновлён.
• Файлы демо приватны для гостей; скачивание доступно вошедшим игрокам по временным ссылкам, удаление — только автору.
• Лимит «одна новая загрузка в час» проверяется серверной SQL-функцией; повтор незавершённой загрузки с тем же именем и размером допускается в течение 15 минут.
• Проверь, что лимит размера Supabase Storage в настройках проекта не ниже 50 МБ.
• Архив не меняет VPS или Supabase автоматически. В этой поставке SQL не выполнялся, сайт не публиковался и тест в живом аккаунте не проводился.
