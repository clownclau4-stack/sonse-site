CF FACEIT v51 — имена авторов демо

ФАЙЛЫ
• CF_FACEIT_V51_DEMO_AUTHORS.zip — полная папка сайта PAGES_UPLOAD и отдельная миграция SQL/44.
• SQL/44_demo_author_attribution.sql — standalone SQL для поля автора в общем списке демо.

УСТАНОВКА
1. Сделай резервную копию текущего сайта и базы данных.
2. Убедись, что ранее уже установлена SQL/43_game_demos.sql. Затем запусти в Supabase SQL Editor файл SQL/44_demo_author_attribution.sql. Миграция заменяет только функцию чтения демо-ленты; таблицы и загруженные файлы она не меняет.
3. Загрузи содержимое PAGES_UPLOAD из архива в корень сайта на VPS, сохранив папки audio, icons и images, а также manifest.webmanifest и sw.js.
4. Войди в онлайн-аккаунт и открой меню «Демки». На каждой карточке проверь подпись «Автор», имя и аватар загрузившего игрока. Другой вошедший аккаунт получает то же имя автора в общей ленте.

ВАЖНО
• Авторы видны во всей общей ленте всем вошедшим игрокам; гостевой просмотр не включён.
• Имя берётся из публичного display_name профиля, с запасным вариантом на ник. Права доступа к демо-файлам и текущий лимит загрузки не меняются.
• SQL в живом Supabase не запускался, а сайт на VPS не публиковался этой сборкой.
