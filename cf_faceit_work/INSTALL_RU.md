# LX FACEIT для Standoff 2 — полный комплект установки

В ZIP находится одна папка `LX_FACEIT_STANDOFF2` с сайтом (HTML, CSS, JavaScript, картами, иконками и PWA), полным SQL-базисом LX и исходниками Supabase Edge Functions. Не скачивай и не собирай отдельно SQL/CSS/JS.

## Важно перед установкой

1. Создай **отдельный Supabase-проект LX FACEIT**. Не подключай сайт и не запускай этот SQL в проекте CF FACEIT или в базе другой игры.
2. Выполни в SQL Editor один файл `SQL/LX_FACEIT_FULL_SETUP.sql`. Он включает базовую схему, регистрацию, профиль, друзей, лобби, подбор матчей, результаты, администрирование, поддержку, турниры и карты Standoff 2. Этот файл уже включает совместимость из прежнего SQL/52 — отдельный запуск SQL/52 не нужен.
3. Установщик намеренно пропускает старый SQL/19, который удалял таблицу очереди, и SQL/31, который очищал матчи. Никакие данные не должны очищаться установкой.
4. После успешного SQL зарегистрируй основателя обычной формой сайта, подтверди почту и только затем используй `SQL/53_lx_founder_bootstrap.sql` с проверенным UUID именно этого аккаунта. Этот шаблон не создаёт аккаунт и не задаёт пароль.

Технические имена части таблиц, RPC и хранилищ сохраняют префикс `cf_` ради совместимости с текущим JavaScript. Они создаются внутри отдельного проекта LX и не подключают базу CF.

## Сайт

1. Загрузи **содержимое `PAGES_UPLOAD/`** в корень HTTPS-хостинга. Не загружай туда SQL-файлы.
2. В `PAGES_UPLOAD/js/config.js` задай URL выделенного LX Supabase и его публичный anon/publishable key:

   ```js
   window.LX_SUPABASE_URL = 'https://YOUR-LX-PROJECT.supabase.co';
   window.LX_SUPABASE_ANON_KEY = 'YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY';
   ```

   В этот файл нельзя помещать `service_role`, секретные или административные ключи.
3. В настройках Auth разреши регистрацию по электронной почте, настрой подтверждение email и добавь домен сайта в разрешённые Redirect URLs.
4. Для входа по нику опубликуй `supabase/functions/login-by-nickname/index.ts` как Edge Function `login-by-nickname`. Вход по email использует Auth напрямую. Исходники функций оплаты Telegram и проверки скриншотов тоже находятся в `supabase/functions/`; это необязательные интеграции и требуют свои секреты.

## Границы проверки

Архив включает полный фронтенд и SQL-установщик. Локально проверены связи между используемыми фронтендом RPC и определениями SQL, синтаксис JavaScript/HTML и SQL-грамматика. SQL не применялся к Supabase, Edge Functions не развёртывались, регистрацию, вход, реальные матчи и production не проверял.
