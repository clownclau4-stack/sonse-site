# LX FACEIT — Standoff 2

LX FACEIT теперь занимает основной каталог сайта `PAGES_UPLOAD/` вместо CF FACEIT; это одна сборка сайта, не отдельный соседний проект. ZIP-пакет содержит этот файл, сайт и две миграции.

## Что работает сейчас

- Страницы, игровые карты Standoff 2, регистрационная форма и переходы по шагам работают в браузере.
- Поля входа и регистрации можно заполнять, даже пока сервер не подключён.
- Создание учётной записи, вход, матчи, рейтинг и администрирование требуют отдельной настроенной базы LX Supabase. Отправка форм остаётся отключённой без неё — сайт не создаёт локальные фиктивные аккаунты.
- `PAGES_UPLOAD/js/config.js` намеренно содержит пустые настройки. Не подключайте сайт к Supabase CF FACEIT: смешивать пользователей, матчи и ELO разных игр нельзя.

## Публикация сайта

Загрузите **содержимое `PAGES_UPLOAD/`** в корень существующего HTTPS-хостинга вместо прежних файлов CF FACEIT. Версия service worker обновлена для LX и заменяет старый кеш этого сайта.

## Серверная часть

Отдельный проект LX Supabase и совместимая базовая схема v9 ещё не подготовлены. SQL/52 — не установщик с нуля: он требует существующие таблицы и функции, включая профили, подбор матчей, модерацию и турниры; запускайте его только после этой базовой схемы в выделенной LX-базе. Скрипт откажется менять карты, если в очереди или турнирах остались несовместимые записи.

После безопасной регистрации и подтверждения почты SQL/53 может выдать роль основателя уже созданному аккаунту. Он требует проверенных UUID из Supabase Auth и совпадающего ника; сам аккаунт или пароль скрипт не создаёт. Не публикуйте пароли, `service_role` или другие секреты в конфигурации сайта.

Текущие серверные данные CF не удалялись и не подключаются из LX. Миграции LX в этом изменении не применялись; реальную регистрацию и игровые действия без выделенного LX backend проверить нельзя.

## Файлы

- `PAGES_UPLOAD/` — единственная текущая версия фронтенда.
- `SQL/52_lx_standoff2_maps_and_ids.sql` — добавочная миграция карт и игрового ID для совместимой LX-схемы.
- `SQL/53_lx_founder_bootstrap.sql` — шаблон выдачи роли основателя существующему аккаунту.
