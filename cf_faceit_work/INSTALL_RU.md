# CF FACEIT — установка обновления игры и ELO

## Статический сайт

1. Распакуйте ZIP. Для публикации загрузите **содержимое `PAGES_UPLOAD/`** в корень статического сайта. Это каноническая сборка; корневые `index.html` и `cf_faceit_work/index.html` — другие страницы.
2. Убедитесь, что `PAGES_UPLOAD/js/config.js` указывает на нужный Supabase-проект. В браузере допустим только публичный publishable/anon key; `service_role` и AI-ключи в сайт добавлять нельзя.
3. Обновлённый service worker меняет версию кэша, чтобы браузеры загрузили новый ELO-текст и JS.

## Существующая Supabase-база

`SQL/50_skill_based_elo_and_ai_review.sql` из ZIP — **добавочная миграция для уже установленной v9 базы**; она рассчитана на `public.profiles`, `public.cf_lobby_matches` и функции из предыдущей цепочки, включая SQL/33 и SQL/49. Перед применением сохраните резервную копию и проверьте миграцию на staging. Она не очищает профили, историю, очередь или текущие значения ELO; новый расчёт действует только для будущих результатов, одобренных администратором.

Новый рейтинг использует средний ELO команд и стандартную формулу Elo с K=32: сюрпризная победа приносит больше, ожидаемая — меньше; изменение симметрично между командами. Точная сумма определяется сервером. Состояние матча блокируется и переводится в `done` в одной транзакции, поэтому повторная отправка не выдаёт очки повторно.

OCR — только подсказка для администратора. Служебная RPC ограничивает попытки проверки одним матчем тремя обращениями, а прямое начисление рейтинга из AI запрещено. Не ставьте результат в `done` до просмотра скриншота и выбора победителя администратором.

SQL/50 **не является полной установкой новой базы** и не означает, что всю историю SQL/01–49 можно безопасно запускать повторно. Старые скрипты пересекаются по схеме; SQL/19 и SQL/31 содержат операции очистки и не должны включаться в обычный installer.

## Edge Function проверки скриншота

Исходник функции находится в `supabase/functions/cf-score-ai/index.ts`. Чтобы развернуть его в отдельном Supabase-проекте, запустите из корня распакованного ZIP (где лежит папка `supabase/`):

```bash
supabase functions deploy cf-score-ai --project-ref <project-ref>
```

Для реального OCR нужен хотя бы один серверный секрет `GEMINI_API_KEY` или `ANTHROPIC_API_KEY` в Supabase Edge Function secrets. Если ни одного нет, функция безопасно вернёт `no_ai_key`; игра и ручная проверка администратора остаются доступными. Не передавайте ключи чатом и не помещайте их в ZIP сайта.

## Проверки исходников

Из корня репозитория:

```bash
node --check cf_faceit_work/PAGES_UPLOAD/js/app.js
node --check cf_faceit_work/PAGES_UPLOAD/js/config.js
node --check --input-type=module < cf_faceit_work/supabase/functions/cf-score-ai/index.ts
python3 -m unittest discover -s cf_faceit_work/tests -v
```

Локальные тесты проверяют синтаксис, файлы и заявленные SQL/UI-инварианты; они не доказывают отсутствие всех уязвимостей и не заменяют проверку реального аккаунта, матча, OCR-ключей и поведения production. Не меняйте вручную значения ELO в профиле: рейтинг должен изменяться только через серверную проверку результата.
