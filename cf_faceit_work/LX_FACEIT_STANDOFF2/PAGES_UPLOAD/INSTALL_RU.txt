LX FACEIT для Standoff 2 — установка

Сайт: содержимое этой папки загрузите в корень HTTPS-хостинга.

В js/config.js уже заданы URL выделенного проекта LX Supabase и его публичный publishable key. Чтобы включить регистрацию, сначала выполни полный установщик SQL/LX_FACEIT_FULL_SETUP.sql только в этом проекте и настрой подтверждение email и Redirect URLs. Для входа по нику дополнительно разверни Edge Function login-by-nickname; по email вход использует Supabase Auth напрямую. Не подключай к сайту базы других игр и не помещай в js/config.js ключ service_role.

SQL/53 выдаёт роль основателя только уже зарегистрированному аккаунту по проверенному UUID и совпадающему нику. Пароли в SQL и сайте не хранятся.

Полная инструкция и обе миграции находятся в одном ZIP-пакете. Данные существующих игровых баз не удалялись и с LX не смешиваются. Миграции не применялись; онлайн-регистрация и реальные матчи без отдельного backend не проверены.
