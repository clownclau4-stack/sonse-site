LX FACEIT для Standoff 2 — установка

Сайт: содержимое этой папки загрузите в корень HTTPS-хостинга.

Форма входа и регистрации работает в браузере: поля доступны, а мастер регистрации переключает шаги. Создать аккаунт пока нельзя, потому что выделенная база LX Supabase не подключена. Пустая конфигурация в js/config.js преднамеренная; не подключайте к LX базы и аккаунты других игр и не создавайте локальные фиктивные аккаунты.

Для включения онлайн-функций сначала потребуется отдельный проект LX и совместимая базовая схема. SQL/52 — только дополнительная миграция карт и ID для готовой схемы, не установщик с нуля; применять только в выделенной LX-базе. SQL/53 выдаёт роль основателя только уже зарегистрированному аккаунту по проверенному UUID и совпадающему нику. Пароли в SQL и сайте не хранятся.

Полная инструкция и обе миграции находятся в одном ZIP-пакете. Данные существующих игровых баз не удалялись и с LX не смешиваются. Миграции не применялись; онлайн-регистрация и реальные матчи без отдельного backend не проверены.
