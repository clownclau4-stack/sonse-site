CF FACEIT v55 — выдача рамок через админ-панель

- В панели администратора появилась вкладка «Рамки».
- Администратор или владелец может найти игрока по нику, игровому ID или UUID, выдать выбранную рамку либо снять её.
- Выданные рамки сохраняются в Supabase. При выдаче рамка автоматически становится активной; после снятия активной рамки включится последняя из оставшихся.
- Активная рамка видна всем игрокам в профиле, поиске, рейтинге, списке друзей, демках, лобби и общем чате.
- Выдать рамку самостоятельно нельзя: сервер разрешает активировать только запись из инвентаря, добавленную через админ-функцию.

Установка: после SQL/42_sponsor_badge_and_profile_customization.sql выполните SQL/47_shop_avatar_frames.sql в Supabase, затем загрузите обновлённое содержимое PAGES_UPLOAD на сайт. Миграция добавляет инвентарь рамок, защищённую RPC-функцию и поле текущей рамки профиля. SQL автоматически не выполнялся.
