CF FACEIT v48 — исправлен вход по никнейму

- Войти можно по нику и паролю либо по почте и паролю.
- Игровой ID больше не запрашивается и не сверяется при входе. Он остаётся обязательным уникальным полем регистрации.
- Серверная Supabase Edge Function сопоставляет никнейм с профилем и проверяет пароль через Supabase Auth.

Установка
1. Распакуй архив v47. Из корня папки, где находится PAGES_UPLOAD, примени NICKNAME_LOGIN_V48.patch командой `patch -p1 < NICKNAME_LOGIN_V48.patch`.
2. Загрузи обновлённую папку PAGES_UPLOAD на VPS.
3. В Supabase Edge Functions обнови функцию login-by-nickname кодом из edge-function-code/login-by-nickname.ts.txt и выполни Deploy.
4. SQL/38_auth_registration_login_hardening.sql должен быть установлен. Новая SQL-миграция не нужна.

Проверка
Патч чисто применяется к PAGES_UPLOAD из архива v47; синтаксис JavaScript страницы и сценарий входа проверены. Вход в реальный аккаунт не проверен: живая Supabase и VPS не подключены, поэтому изменения нужно опубликовать отдельно.
