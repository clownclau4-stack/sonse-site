CF FACEIT v55 — выдача рамок игрокам через меню администратора

Что добавлено
- В админ-панели есть вкладка «Рамки»: укажи ник, игровой ID или UUID, выбери рамку и нажми «Выдать рамку» или «Снять выбранную рамку».
- Доступ к действию проверяется сервером Supabase; выдавать могут только аккаунты с ролью admin или founder.
- Выданная рамка сохраняется в инвентаре игрока и автоматически отображается в его аватаре. Её увидят остальные игроки в профиле, рейтинге, друзьях, демках, лобби и общем чате.
- Снятие рамки удаляет её из инвентаря; если она была активной, автоматически выбирается последняя оставшаяся. При снятии последней рамки аватар возвращается к обычному виду.
- Владелец сохраняет право выдавать рамки администраторам; администратор может выдавать рамки только обычным игрокам.

Установка
1. Откройте Supabase → SQL Editor.
2. Если миграция SQL/42_sponsor_badge_and_profile_customization.sql ещё не применялась, выполните её (после SQL/41).
3. Выполните SQL/47_shop_avatar_frames.sql из комплекта. Запускать повторно безопасно.
4. Загрузите содержимое папки PAGES_UPLOAD на сайт и обновите страницу.

Покупка через Telegram по-прежнему согласуется вручную. Этот SQL не принимает оплату и сам по себе не выдаёт платную рамку: выдачу выполняет администратор после подтверждения.
