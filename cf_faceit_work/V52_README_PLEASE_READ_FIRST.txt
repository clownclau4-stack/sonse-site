CF FACEIT v52 — профиль и видео демок

Что изменилось:
- Профиль: квадратная аватарка с закруглёнными углами слева; ник, значок и уровень FACEIT рядом; ELO и место в рейтинге — в той же строке.
- Социальные сети вынесены в отдельный блок профиля.
- В разделе «Демки» можно загружать .dem и .mp4 размером до 50 МБ. Для каждого игрока сохраняется лимит: одна загрузка в час.
- Обновлён экран выбора файла и кнопка загрузки.
- Добавлена версия service worker, чтобы установленная PWA подхватила обновлённую оболочку.

Установка SQL в Supabase (SQL Editor):
1. Если SQL/42_sponsor_badge_and_profile_customization.sql ещё не применён, сначала установи SQL/41_player_host_and_moderation.sql, затем SQL/42_sponsor_badge_and_profile_customization.sql. SQL/42 нужен для выдачи значка спонсора, хранения фона профиля и изменения стиля ника.
2. Для MP4 сначала должна быть установлена SQL/43_game_demos.sql. Затем выполни SQL/45_mp4_game_demos.sql — он расширяет прежнюю настройку демо и разрешает .mp4.
3. Если ещё не применял SQL/44_demo_author_attribution.sql, выполни его после SQL/43_game_demos.sql, чтобы показывать автора в общей ленте демок.
4. Не запускай повторно уже успешно установленные миграции без необходимости.

Публикация сайта:
1. Распакуй архив.
2. Загрузи содержимое папки PAGES_UPLOAD в корень сайта на VPS, заменив старые файлы.
3. Обнови страницу сайта. Если установлено как PWA, закрой и снова открой приложение, чтобы оно активировало обновлённый service worker.

После SQL/42 администратор может выдавать значок спонсора через админ-панель → «Управление ролями» → «Значок спонсора». После SQL/45 новая форма принимает .dem и .mp4; правило одной загрузки в час действует для обоих типов файлов.

Этот архив не загружает сайт на VPS и не выполняет SQL автоматически.
